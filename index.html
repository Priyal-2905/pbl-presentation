Epilepsy Detection

Automated detection of epileptic seizures through EEG signal analysis using Deep Learning and Convolutional Neural Networks.

Problem Statement

The manual examination of Electroencephalogram (EEG) for epilepsy is a time-consuming and tedious process requiring highly skilled professionals, leading to potential diagnostic delays and observer variability. Current methods either lack sufficient accuracy, generalization, or are not real-time applicable. There is a critical need for an accurate, efficient, and reliable automated system which can detect epileptic seizures in real-time, while maintaining high sensitivity and specificity to reduce false negatives and false alarms, thereby enabling medical professionals to intervene on time to improve patient outcomes.

Literature Review

Analyzed 10 state-of-the-art models including Multiscale CNN (Truong et al., 98.1%), LSTM Networks (Hussein et al., 97.5%), EEGNet (Lawhern et al., 89.4%), Ensemble Deep Learning (Wei et al., 99.1%), Transfer Learning approaches, Attention-based CNNs, and Graph CNNs. Datasets: CHB-MIT (664 hours, 24 patients), Bonn University EEG, TUH EEG.

Research Gap

Unlike traditional ML approaches requiring manual feature engineering, our CNN-based solution automatically extracts both spatial (electrode relationships) and temporal (brain activity patterns) features from raw EEG data. Multi-class classification into 3 states (Inter-icatal,Ictal,Post-ictal) enables comprehensive seizure monitoring across the entire seizure cycle, not just detection during seizures.

System Methodology

Data Pipeline

CHB-MIT: 664 hours, 24 patients, 23 channels @ 256 Hz | Bonn: 5 sets (Z,O,N,F,S), 100 segments each | Preprocessing:5-second windows with 1 second stride

Architecture

1D CNN: Conv1D Blocks: 8 filters (k=6) → 8 filters (k=5) → 16 filters (k=4) → 16 filters (k=4) → 32 filters (k=4) | Each block: Conv1D → ReLU → MaxPool | GlobalAveragePooling1D | FC Layers: 50 → 20 neurons | Output: 3-class SoftMax

Results & Analysis

Test Accuracy 95.53%
Sensitivity 97.13%
Specificity 95.47%

CNN model achieved 95.1% accuracy on the CHB-MIT dataset,comparable to the best existing models. The model successfully classifies EEG signals into 3 states: Inter-ictal, Ictal, and Post-ictal, enabling comprehensive seizure monitoring and early intervention.
